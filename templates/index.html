Technology Stack & Methodology
Technology Stack:
  • MediaPipe: Hand detection and landmark extraction
  • OpenCV: Video processing and image manipulation
  • Flask: Web framework for real-time streaming
  • Bootstrap: Responsive UI framework
Recognition Methodology:
  • Hand Detection: MediaPipe detects hand landmarks in real-time
  • Feature Extraction: 21 key points tracked per hand
  • Rules-based Classification: Finger position analysis
  • Real-time Processing: 30 FPS gesture recognition
